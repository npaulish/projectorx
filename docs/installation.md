# Installation

## Stable release

To install Projector Extensions, run this command in your terminal:

```sh
uv add projectorx
```

Or if you prefer to use `pip`:

```sh
pip install projectorx
```

## From source

The source files for Projector Extensions can be downloaded from the [Github repo](https://github.com/npaulish/projectorx).

You can either clone the public repository:

```sh
git clone git://github.com/npaulish/projectorx
```

Or download the [tarball](https://github.com/npaulish/projectorx/tarball/master):

```sh
curl -OJL https://github.com/npaulish/projectorx/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd projectorx
uv pip install .
```
