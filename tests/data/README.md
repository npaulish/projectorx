# Test data

These files are used only by the test suite. Most of them are third-party data,
redistributed unmodified under their own licences, which are separate from
projectorx's MIT licence. They are excluded from the projectorx distributions
(see `prune tests` in `MANIFEST.in`).

## Pseudopotentials

`Co.upf` and the K file were generated with ONCVPSP by D. R. Hamann (GNU GPL).
As their file headers request, please cite D. R. Hamann, Phys. Rev. B 88, 085117
(2013). The Ti file was generated with the Vanderbilt ultrasoft code.

## Files generated by projectorx

- `broken.upf`: a deliberately invalid file, used to check that `extend-library`
  skips files it cannot read.
- `Co_reference.dat`, `sssp/K_reference.dat`, `sssp/Ti_reference.dat`: reference
  `extend-upf` outputs for the pseudopotentials above. The K and Ti references were
  generated by projectorx on 2026-11-25. They are regression baselines, not
  independent results; regenerate them only when an output change is intended.
